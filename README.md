# 星云弹幕助手
全平台直播弹幕采集助手，支持抖音、视频号、快手、小红书、淘宝、京东、拼多多、B站、Tiktok等。
内置弹幕墙功能，可自定义消息上墙，也可根据弹幕墙示例编写自己的弹幕墙。
提供转发功能，将弹幕消息转发到第三方应用上。

最新版本 0.0.1.715
