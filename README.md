# 星云弹幕助手
全平台直播弹幕采集助手，支持抖音、视频号、快手、小红书、淘宝、京东、拼多多、B站、Tiktok等。
内置弹幕墙功能，可自定义消息上墙，也可仿照弹幕墙示例制作自己的弹幕墙。
提供弹幕转发功能，在直播间页面设置是否转发到第三方应用上。开启后，在弹幕收集时自动转发到配置的第三方接口。

最新版本 0.3.8.1
